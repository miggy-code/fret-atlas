# STORY-022 — Practice selected scale degrees with assistance

## Friction Scorecard

| Measure | Evidence | Result |
|---|---|---|
| Steps | Select degree chips → Start → Hint if needed → find/reveal | 4 / 4 ideal |
| Decisions | Select degree subset; optionally choose hint or reveal | Necessary learning choices |
| Re-entry | None | 0 |
| Confirmations | None | 0 |
| Dead ends | End preserves selections and returns focus to the degree drill | 0 |
| Hesitations | The degree chips present both a note and interval, but the Start button itself is repeated on three cards | 1 suspected |

Live evidence: Practice shows Find notes, Find scale degrees, Find chord tones, and Play through together. Each drill card has a generic **Start** button; keyboard and screen-reader users have IDs, but visual scanning does not reveal which Start belongs to which exercise without reading the full card.

Verdict: **acceptable**. The flow matches the ideal path, but the repeated primary label weakens recognition when the three cards are scanned quickly.

## Take-away Pass

- Keep degree chips visible before starting because they define the drill.
- Keep the assistance controls inside an active drill; they are correctly deferred until needed.
- Replace the three identical **Start** labels with goal-specific labels: **Find notes**, **Find selected degrees**, and **Find chord tones**. This removes a recognition decision without adding a step.

## The Simpler Version

1. Select the degree chips to practice.
2. Choose **Find selected degrees**.
3. Use **Need help** only if stuck, then complete or reveal the round.

## Clarity Issues

- “Start” is repeated across distinct drill cards. The surrounding headings provide context, but users have to bind label and card visually before acting.
- The credit rule appears lower in the Progress section, not alongside Hint/Reveal. When assistance is used, briefly say “Assisted round — no progress credit” in the drill feedback.
